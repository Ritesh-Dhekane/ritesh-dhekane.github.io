- Five templates (including Jake's Resume), a structured form and a **live A4 preview**; export as image or PDF.
- Fully client-side: nothing is uploaded; saves fall back to the browser and a JSON download.
- Also my own resume workspace: saved versions and an archive of past PDFs.
- Privacy-safe analytics (events only, never resume content); deployed with GitHub Actions to GitHub Pages.
