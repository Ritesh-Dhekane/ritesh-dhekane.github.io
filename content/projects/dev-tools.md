- **Page checker:** headless Chrome checks for accessibility, horizontal overflow, console errors and screenshots at phone sizes.
- **Apps Script harness:** runs a Google Apps Script web app locally with fake Drive, Cache and Properties, so it can be tested without deploying.
- **Document and image readers:** turn PDFs, Word and PowerPoint files into compact text, and read screenshots with the OCR built into Windows.
- **Mermaid checker, repo sync, GitHub run waiter** and more — each one written the second time a chore came up. (Some live in a private repo.)
