- Study content is kept separate from the app: source PDFs → processed Markdown → JSON indexes for navigation and search, with no backend.
- Subject and unit navigation, local search, syntax highlighting, an audio reader and notification controls.
- Deployed to GitHub Pages with GitHub Actions. Its successor is 2AM Notes Pro.
